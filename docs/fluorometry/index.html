Reading these spectra

  • Raw S1 is not the excitation spectrum. The xenon lamp output swings ~8× across 400–650 nm, which drags every raw λex down to a uniform 467–468 nm. Switching the channel to S1 ÷ R1 (the reference photodiode) restores 484–490 nm — the real sfGFP maximum. This reproduces independently in both runs.
  • Normalise before comparing shape. With each scan set to peak = 1, the three constructs lie on top of each other — λex ≈ 486, λem ≈ 508 — so the tet insertions do not measurably perturb the chromophore. Brightness is the only thing separating them.
  • Sample number → construct is an assignment, not a measurement. 1 = 0-tet, 2 = 1-tet, 3 = 2-tet, carried over from attempt 1's scan ordering. Each page restates it in its own notes.
