Reading these spectra

  • Raw S1 is not the excitation spectrum. The xenon lamp has sharp emission lines at 467 and 473 nm, and its output swings ~8× across the sweep — that, not the protein, is what pins every raw λex to a uniform 467 nm. The reference photodiode R1 spikes at exactly the same wavelengths, so switching the channel to S1 ÷ R1 cancels the lines and leaves a smooth band peaking at 485–490 nm — the real sfGFP maximum. This reproduces independently across all three runs.
  • Concentration is not free of consequences. The ×2→×32 ladder returns 10.6× the emission for 16× the material, and its emission maximum walks from 507.3 to 510.7 nm as it brightens. Both are reabsorption — the inner-filter effect — so above roughly ×16 the response is no longer proportional, and absolute λem should not be compared across runs of different brightness.
  • Normalise before comparing shape. With each scan set to peak = 1, the three constructs lie on top of each other — λex ≈ 487, λem ≈ 508 — so the tet insertions do not measurably perturb the chromophore. Brightness is the only thing separating them.
  • Sample number → construct is an assignment, not a measurement. 1 = 0-tet, 2 = 1-tet, 3 = 2-tet, carried over from attempt 1's scan ordering. Each page restates it in its own notes.
